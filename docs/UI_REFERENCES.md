# UI reference pass — 3 November 2026

The connected Google Drive folder **Referensi UI — ATRI & Please Be Happy** was inspected after the user's new direction. All twelve images were downloaded for internal review: seven ATRI screens and five Please Be Happy screens. Their source index was read; copyrighted reference images are not committed or packaged.

## What was observed and applied

| Reference evidence | Madoromi change |
|---|---|
| ATRI title: large environment, left-aligned navigation, restrained controls | Full courtyard title with smaller heroine and readable left navigation; remove opaque half-screen panel. |
| ATRI dialog: art dominates; compact lower-right toolbar | Separate narration shading and a compact labeled touch toolbar. |
| Please Be Happy dialogue and quick-menu screenshots: light balloons, serif reading text, contextual edge menu | Warm ivory speech panel, licensed Noto Serif, a small contextual menu using native actions. No per-line hand-positioned text. |
| ATRI system tabs, grouped settings | Horizontal menu tabs; preferences separated into reading, sound and controls. Voice controls are omitted because the game has no voice acting. |
| ATRI save/load: image, date and clearly grouped slots | Four larger native slots per page, numeric dates, autosave/quick pages and accessible deletion. |
| ATRI backlog: distinct entries and jump controls | Readable speaker/text rows and native rollback actions only when the checkpoint remains available. |
| Please Be Happy long narration / split-scene examples | Separate narration presentation; the gift scene uses an illustrated inset while keeping the heroine and text readable. |
| Please Be Happy choices | Choices stay in the lower composition, leaving the heroine's face clear. |

The source screenshots do not establish exact font families, all animation implementations, or rights to their music. Madoromi retains its own licensed typography, existing soundtrack and separate ambience/SFX. No reference art, ornaments, UI texture, character, music or voice is extracted for runtime.

## Review method

Ren'Py Galgame Builder preserves story labels and native systems. Game UI/UX checks scaling, safe margins, input and actual screens. UI UX Pro Max supplies touch/contrast guidance; its web examples are not copied into Ren'Py. Impeccable's context and craft/polish references guide visual hierarchy and final inspection. Installed versions and provenance are in `docs/SKILLS.md`.

The project's geometric widget textures are original programmatic UI shapes, not copied reference graphics. Character expressions remain consistent licensed 2D assets; the stage uses short native ATL entrances, framing and dissolves rather than an unproven Live2D rig. Actual render and device-test results belong in `docs/VERIFICATION.md`.

Android calibration enlarged critical hit regions from 72 to 108 virtual units after measuring the 240 dpi emulator. Settings gained a scroll area below fixed tabs, and page/slot layout was adjusted to retain four visible slots. Font controls are placed first so readers can enlarge text immediately.
