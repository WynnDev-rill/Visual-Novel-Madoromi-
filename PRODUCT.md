# MADOROMI

A complete Indonesian-language romance visual novel set in a fictional Japanese coastal town. The player follows Ren and Aoi from late-night friendship through an explicit reciprocal confession, a handmade gift and an afterstory. Five choices change tone and later callbacks. Three chapters and the original source ending remain intact.

Primary delivery is an installable offline Android APK; desktop is also supported. No character voice acting. Music, ambience and soft interface sounds support reading. Use native Ren'Py persistence, rollback, history, auto, skip, UI scaling and packaging.

The user explicitly delegates routine production decisions and requests autonomous completion. The current interface direction is pinned by their Google Drive collection **Referensi UI — ATRI & Please Be Happy**, all twelve screenshots inspected on 2026-11-03. Take art-forward composition, clear segmented system screens, warm dialogue treatment and restrained 2D expression/staging principles. All game art and audio must have its own legal source; reference images are not runtime assets.

Preserve completed story/assets/toolchain work; improve Android readability and actual runtime behavior. No Live2D rig is required. Quality must be supported by screenshots, native tests and an actual signed APK launch, with physical-device limits stated honestly.
