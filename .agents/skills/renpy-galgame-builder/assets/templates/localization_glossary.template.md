# Localization Glossary

## Supported Languages

- English
- Traditional Chinese (`tchinese`)

## Core Terms

| English | Traditional Chinese | Notes |
|---|---|---|
| Truth | 真相 | Use for status/UI. |
| Corruption | 腐化 | Use for route/stat systems. |
| Intimacy | 親密度 | Use for status/UI. |
| Core Collapse | 核心崩毀 | Ending title pattern. |

## Character Voice

- NOVA-like character: calm, elegant, protective, subtly possessive.
- MAYA-like character: warm, guilty, exhausted, emotionally restrained.
- HYDRA-like character: seductive, playful, poetic, dangerous but wounded.
- System narration: clinical, ritualistic, concise.

## Font Rule

Bundle a CJK-capable font inside `game/fonts/` and set Ren'Py GUI/custom styles to use it. Do not rely on the developer machine's installed fonts.
